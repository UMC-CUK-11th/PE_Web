# UMCine 이미지 에셋 출처

이 파일은 `public` 안의 외부 이미지와 로고 출처를 기록하기 위해 존재해요. 이미지의 사용처를 확인하거나 교체할 때 참고하세요. 실제 이미지 경로는 `src/data/movies.ts`와 각 화면 컴포넌트에서 지정합니다.

이 ZIP은 UMC 웹 파트 실습용으로 준비한 포스터 10개, 배경 이미지 10개와 TMDB 출처 표기용 로고를 담고 있어요.

`images/movies/`의 일반 `.jpg` 파일은 카드와 상세 화면의 포스터이고, 이름에 `-backdrop`이 붙은 `.jpg` 파일은 상세 화면의 넓은 배경입니다. JPG는 코드 주석을 넣을 수 없는 이미지 파일이라 이 문서에서 역할을 설명합니다.

- `images/logos/tmdb-logo.svg`: TMDB가 제공하는 공식 `Alt short (blue)` SVG 로고 - https://www.themoviedb.org/about/logos-attribution

- `spider-man-brand-new-day-backdrop.jpg`: UMCine Figma 시안에서 사용한 TMDB 배경 이미지 - https://www.themoviedb.org/movie/969681-spider-man-brand-new-day
- `odyssey-backdrop.jpg`: https://www.themoviedb.org/movie/1368337
- `spider-man-no-way-home-backdrop.jpg`: https://www.themoviedb.org/movie/634649
- `last-house-backdrop.jpg`: https://www.themoviedb.org/movie/1284041
- `minions-monsters-backdrop.jpg`: https://www.themoviedb.org/movie/878357
- `colony-backdrop.jpg`: https://www.themoviedb.org/movie/1375646
- `toy-story-5-backdrop.jpg`: https://www.themoviedb.org/movie/1084244
- `death-of-robin-hood-backdrop.jpg`: https://www.themoviedb.org/movie/1284465

TMDB 로고는 색상, 비율이나 방향을 변경하지 않고 사용해 주세요. 화면의 출처 표기 영역에는 다음 문구를 함께 표시해요.

`This product uses the TMDB API but is not endorsed or certified by TMDB.`

영화 메타데이터와 위 배경 이미지는 TMDB를 참고했어요.
