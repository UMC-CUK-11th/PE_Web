검증한 항목:

- 초기 가입 버튼 잠금, 이메일 형식, 닉네임 2/12자 및 범위 밖 입력
- 비밀번호 대소문자/숫자/특수문자 조합, 8/72자 경계 및 비밀번호 확인
- 이메일·닉네임 중복 확인, 확인 중 입력 잠금, 확인 실패 후 재시도
- 확인한 입력 변경 시 이전 확인 무효화
- 가입 중 상태, 추가 submit 이벤트가 있어도 POST 한 번만 전송
- passwordConfirm 미전송 및 실제 성공 응답의 password 미포함
- 서버 409 및 네트워크 실패 시 메시지 표시/입력 유지
- 201이라도 계약과 다른 응답이면 오류로 처리하고 입력 유지
- 실제 Spring Boot/H2에 가입 후 같은 이메일·닉네임을 다시 확인하면 중복 표시
- 로그인 입력 및 로그인 API를 호출하지 않는 퍼블리싱 상태
- 내 정보 수정·취소·저장 후 조회 반영과 새로고침 시 예시 초기화
- 신규 4개 화면 직접 접속, 런타임 오류 없음, 수평 넘침 없음

브라우저 테스트의 오류·지연 응답은 모의 처리했고 실제 가입 테스트 2개만 실제 서버를 사용했다. 내 정보 화면은 예시 데이터이며 실제 회원 수정 검증이 아니다. 다른 브라우저 엔진과 실물 모바일 기기, 원문에 빠진 디자인 시안과의 일치 여부는 검증하지 않았다.

캡처는 docs/week07-evidence에 12장 저장했다. live-h2 파일은 실제 서버/H2 결과, pending-mocked 파일은 지연 모의 응답 결과다. 로그인·내 정보 화면은 이번 주차 퍼블리싱 결과다.

추가 캡처 검증: 전체 기능 테스트 22개 통과 후, 긴 페이지의 sticky 헤더가 캡처 중간에 찍히지 않도록 캡처 전에 스크롤을 맨 위로 이동했다. 캡처 관련 10개 테스트를 다시 실행해 10 passed (25.1s)를 확인하고 12장의 이미지를 교체했다. 현재 로컬 HTML 보고서는 이 마지막 캡처 검증 10개를 표시한다.
