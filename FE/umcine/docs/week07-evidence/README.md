# 화면 캡처 설명

이 폴더의 파일은 2026-11-11 실제 Chromium 테스트 실행 중 저장한 스크린샷입니다.

- 01~04: 필수 미션의 로그인/내 정보 조회/수정 및 수정 반영. 내 정보는 예시 회원입니다.
- 05: 실제 화면의 입력 검증 상태. 서버 호출 전입니다.
- 06~08: 실제 Spring Boot 서버 및 임시 H2 DB의 회원가입/중복 확인 결과입니다. MySQL 검증 결과가 아닙니다.
- 09: 진행 상태를 확인하기 위해 지연 응답을 모의 처리했습니다.
- 10~12: 모바일 뷰포트의 필수 화면입니다. 실물 모바일 기기에서 촬영한 결과는 아닙니다.

원문은 정해진 인증 캡처 장수를 지정하지 않았습니다. Notion의 필수 미션에는 01~04를, 본문 실습 결과에는 05~08을 첨부하면 됩니다. 09~12는 추가 검증 자료입니다. 핵심 코드 링크와 선택 미션 폴더 설명도 함께 기록하세요.
