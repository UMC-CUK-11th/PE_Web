# UMCine

UMC CUK 11th 프로젝트 저장소입니다.

## 폴더 구조

```text
PE_Web/
├── FE/
│   ├── week1-typescript/
│   ├── week2-react/
│   └── week3-react/
├── .gitignore
└── README.md
```

- `FE/week1-typescript`: 1주차 TypeScript 미션
- `FE/week2-react`: 2주차 React 영화 목록 미션
- `FE/week3-react`: 3주차 TanStack Router 및 Tailwind CSS 미션
- `BE`: 백엔드 프로젝트 추가 시 저장할 예정입니다.

## 최신 프론트엔드 실행

```bash
cd FE/week3-react
pnpm install
pnpm dev
```

## 검사

```bash
cd FE/week3-react
pnpm build
pnpm lint
```
